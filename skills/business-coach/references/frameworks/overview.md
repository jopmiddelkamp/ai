## 🔷 THE VTO — Vision/Traction Organizer
**Source: Traction — Gino Wickman**

The single most complete one-page business operating system ever created.
Every business needs all 6 components working simultaneously.

```
┌─────────────────────────────────────────────────────────┐
│                    THE VTO                              │
├──────────────┬──────────────────────────────────────────┤
│   VISION     │  Where are we going and why?            │
│              │  • Core Values (3-7 non-negotiables)    │
│              │  • Core Focus (purpose + niche)         │
│              │  • 10-Year Target                       │
│              │  • Marketing Strategy                   │
│              │  • 3-Year Picture                       │
│              │  • 1-Year Plan                          │
│              │  • Rocks (90-day priorities)            │
│              │  • Issues List                          │
├──────────────┼──────────────────────────────────────────┤
│   TRACTION   │  How do we execute?                     │
│              │  • Rocks (quarterly priorities)         │
│              │  • Meeting Pulse (weekly L10 meeting)   │
│              │  • Scorecard (5-15 weekly metrics)      │
│              │  • Process (documented core processes)  │
│              │  • People (right people, right seats)   │
│              │  • Issues (IDS — Identify, Discuss,     │
│              │    Solve)                               │
└──────────────┴──────────────────────────────────────────┘

THE 6 COMPONENTS:
① Vision    — Does everyone know where we're going?
② People    — Do we have the right people in right seats?
③ Data      — Do we have a pulse on the business weekly?
④ Issues    — Are we solving problems at the root?
⑤ Process   — Are core processes documented and followed?
⑥ Traction  — Are we executing with discipline?
```

**The Key Insight:** Most businesses fail not from bad ideas but from weak execution systems. EOS (Entrepreneurial Operating System) gives you the rails to run on.

**Rocks:** 90-day priorities. No more than 3-7 per person. Everything else is noise.

**The L10 Meeting:** Weekly 90-minute leadership meeting.
- Segue (5 min)
- Scorecard review (5 min)
- Rock review (5 min)
- Customer/employee headlines (5 min)
- To-do list (5 min)
- IDS — Issues solving (60 min)
- Conclude (5 min)

```
Current revenue: [amount]
Team size: [number]
3-year goal: [goal]

I need to answer to complete it. Start with Core Values.
```

## 🔷 THE FLYWHEEL
**Source: Good to Great — Jim Collins**

Great companies don't have one defining moment. They have a flywheel — a self-reinforcing cycle that builds momentum over time.

```
                    ┌─────────────┐
              ┌────►│  STEP 1     │────►┐
              │     │ (your first │     │
              │     │  input)     │     ▼
        ┌─────┴──┐  └─────────────┘  ┌──────────┐
        │ RESULT │                   │  STEP 2  │
        │(feeds  │                   │          │
        │ back   │                   └────┬─────┘
        │ in)    │                        │
        └────────┘  ┌─────────────┐      │
              ▲     │   STEP 3    │◄─────┘
              └─────│             │
                    └─────────────┘

Amazon's Flywheel:
Lower Prices → More Customers → More Volume → 
More Sellers → Better Selection → Lower Prices

Your flywheel should be unique to your business.
```

**The Key Insight:** Stop looking for the one big move. Find your flywheel and push it. Every push makes the next push easier.

**How to Build Yours:**
1. What drives your revenue?
2. What drives your customer acquisition?
3. What does more revenue enable?
4. How does that enable more customer acquisition?
5. Connect the loop.

**Claude Prompt:**
```

framework. My business model is [describe]. My main growth lever right 
now is [describe]. Help me map the self-reinforcing cycle that, if I push 
consistently, will build compounding momentum.
```

## 🔷 THE VALUE EQUATION
**Source: $100M Offers — Alex Hormozi**

The formula for creating offers so good people feel stupid saying no.

```
                Dream Outcome × Perceived Likelihood of Achievement
VALUE =    ─────────────────────────────────────────────────────────
                    Time Delay × Effort & Sacrifice

To increase value:
↑ Dream Outcome         (make the prize bigger)
↑ Likelihood            (reduce their skepticism)
↓ Time Delay            (make results faster)
↓ Effort & Sacrifice    (make it easier)
```

**The Grand Slam Offer Components:**
```
1. RESULT          What specific outcome do they get?
2. TIMELINE        How fast do they get it?
3. EFFORT          How hard is it for them?
4. RISK REVERSAL   What if it doesn't work?
5. UNIQUENESS      Why can only YOU deliver this?
```

**The Offer Stack:**
Build a stack of bonuses that make the core offer feel like a steal:
- Core offer (the main thing)
- Bonus 1 (solves obstacle 1)
- Bonus 2 (solves obstacle 2)
- Bonus 3 (adds unexpected value)
- Guarantee (removes risk)

**Claude Prompt:**

```
1. Maximize the dream outcome
2. Increase perceived likelihood
3. Reduce time delay
4. Reduce effort required
5. Build an offer stack
6. Create a compelling guarantee
```

## 🔷 RIGHT PEOPLE, RIGHT SEATS
**Source: Traction — Gino Wickman | Good to Great — Jim Collins**

```
                    RIGHT SEAT?
                    YES        NO
                 ┌──────────┬──────────┐
  RIGHT    YES   │  ✅ KEEP  │  COACH   │
  PERSON?       │  & GROW  │  OR MOVE │
                ├──────────┼──────────┤
          NO    │  MOVE OR  │  ❌ EXIT │
                │  RETRAIN  │  QUICKLY │
                └──────────┴──────────┘

RIGHT PERSON = Shares your core values
RIGHT SEAT   = Has the skills for the role (GWC)
               G = Gets it (understands the role)
```

**The People Analyzer:** Rate every person on your team:
- List your core values (3-5)
- Rate each person: + (mostly yes) / +/- (sometimes) / - (mostly no)
- Anyone with multiple minuses is wrong for your organization

## 🔷 THE FIVE DYSFUNCTIONS PYRAMID
**Source: The Five Dysfunctions of a Team — Patrick Lencioni**

```
              ╔═══════════════════════════╗
              ║   INATTENTION TO RESULTS  ║  ← Level 5 Dysfunction
              ╠═══════════════════════════╣
              ║   AVOIDANCE OF ACCOUNTABILITY  ║  ← Level 4
              ╠════════════════════════════════╣
              ║   LACK OF COMMITMENT           ║  ← Level 3
              ╠════════════════════════════════╣
              ║   FEAR OF CONFLICT             ║  ← Level 2
              ╠════════════════════════════════╣
              ║   ABSENCE OF TRUST             ║  ← Level 1 (Root)
              ╚════════════════════════════════╝

Fix from the bottom up. Trust first. Everything else follows.

TRUST → Built through vulnerability ("I was wrong", "I need help")
CONFLICT → Healthy debate, not personal attacks
COMMITMENT → Everyone commits to decisions even if they disagreed
ACCOUNTABILITY → Peers hold each other accountable (not just managers)
RESULTS → Team results over individual recognition
```

## 🔷 THE DREAM 100
**Source: Dotcom Secrets — Russell Brunson | Never Eat Alone — Keith Ferrazzi**

```
STEP 1: Identify your Dream 100
→ 100 people/companies who already have your ideal customers

STEP 2: Dig your well before you're thirsty
→ Give value before asking for anything
→ Comment, share, promote their work
→ Send gifts, handwritten notes

STEP 3: Buy your way in OR work your way in
→ Paid: ads, sponsorships, affiliate deals
→ Earned: collaborations, features, partnerships

STEP 4: Make the ask
→ Only after establishing genuine relationship
→ Specific, clear, easy to say yes to

THE MATH:
100 targets × 10% conversion = 10 partners
10 partners × average audience size = your new reach
```

## 🔷 THE 4 DISCIPLINES OF EXECUTION (4DX)
**Source: The 4 Disciplines of Execution**

```
DISCIPLINE 1: FOCUS ON THE WILDLY IMPORTANT GOAL (WIG)
→ The ONE goal that matters most right now
→ "From X to Y by When"
→ Example: "Grow revenue from $500K to $1M by Dec 31"

DISCIPLINE 2: ACT ON LEAD MEASURES
→ Lag measures = results (you can't control them directly)
→ Lead measures = inputs (you CAN control these)
→ Example: Lag = revenue. Lead = sales calls per week

DISCIPLINE 3: KEEP A COMPELLING SCOREBOARD
→ Make it visible to the whole team
→ Show leads AND lags
→ Everyone must know: are we winning or losing?

DISCIPLINE 4: CREATE A CADENCE OF ACCOUNTABILITY
→ Weekly WIG session (20-30 min max)
→ Each person reports: commitments kept last week
→ Each person states: commitments for this week

THE WHIRLWIND: Day-to-day operations that consume your team
4DX is what you do DESPITE the whirlwind.
```

```
Help me:
```

## 🔷 PROFIT FIRST SYSTEM
**Source: Profit First — Mike Michalowicz**

```
TRADITIONAL FORMULA:          PROFIT FIRST FORMULA:
Sales - Expenses = Profit     Sales - Profit = Expenses

THE BANK ACCOUNT SYSTEM:
┌──────────────┐
│    INCOME    │  ← All revenue lands here
│   ACCOUNT    │
└──────┬───────┘
       │ Distribute on 10th & 25th
       ├─────────────────────────────────────────┐
       ▼                                         ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────────────┐
│    PROFIT    │  │  OWNER'S PAY │  │  TAX ACCOUNT         │
│   (5-20%)   │  │  (30-50%)    │  │  (15-25%)            │
└──────────────┘  └──────────────┘  └──────────────────────┘
                                              │
                                    ┌─────────▼────────┐
                                    │    OPERATING      │
                                    │    EXPENSES       │
                                    │    (30-40%)       │
                                    └───────────────────┘

TARGET ALLOCATION PERCENTAGES (adjust to your reality):
Revenue < $250K:   Profit 5%, Owner 50%, Tax 15%, OpEx 30%
Revenue $250K-1M:  Profit 10%, Owner 35%, Tax 15%, OpEx 40%
Revenue $1M-5M:    Profit 15%, Owner 20%, Tax 20%, OpEx 45%
Revenue $5M+:      Profit 20%, Owner 10%, Tax 20%, OpEx 50%
```

**Claude Prompt:**

## 🔷 THE R.I.C.H. FRAMEWORK — Business Acquisition
**Source: Main Street Millionaire — Codie Sanchez**

```
R — RESEARCH
  → What businesses align with your skills?
  → Where are motivated sellers? (retiring boomers)
  → Industries: cleaning, plumbing, HVAC, laundromats, 
    landscaping, storage, car washes
  → Find via: business brokers, BizBuySell, direct outreach

I — INVESTIGATE  
  → 3 years of tax returns (not just P&L)
  → SDE: Seller's Discretionary Earnings
    (Net profit + owner's salary + non-cash expenses)
  → SDE multiple: typically 2-4x for Main Street businesses
  → Customer concentration risk (no client > 20% of revenue)
  → Key person dependency (does it run without the owner?)

C — CLOSE THE DEAL
  → Creative financing options:
    • Seller financing (60% of deals) 
    • SBA loans (10% down)
    • Earnout structures
    • Equity partnerships
  → Never pay full price in cash
  → Always include transition period (60-90 days minimum)

H — HOLD & GROW
  → First 90 days: listen, don't change
  → Systematize before optimizing
  → Add revenue streams
  → Build to sell or roll up

THE 3-9-12 METHOD:
3 months: Learn and search
9 months: Due diligence and close
12 months: Stabilize and grow
```

## 🔷 TACTICAL EMPATHY & THE BLACK SWAN METHOD
**Source: Never Split the Difference — Chris Voss**

```
THE CORE INSIGHT: Never compromise. Never split the difference.
Splitting is lazy and leaves value on the table.

KEY TECHNIQUES:

1. MIRRORING
   Repeat the last 3 words of what they said.
   Creates connection. Makes them elaborate.
   "...last 3 words?"

2. LABELING
   Name their emotion before they name it.
   "It seems like you're frustrated with..."
   "It sounds like this is really important to you..."

3. CALIBRATED QUESTIONS
   Never ask "why" (accusatory)
   Ask "how" and "what" questions:
   "How am I supposed to do that?"
   "What is it that makes this so important?"

4. THE ACCUSATION AUDIT
   List every negative thing they might think about you.
   Say them first. Defuses objections before they arise.
   "You're probably thinking I'm going to lowball you..."

5. NO-ORIENTED QUESTIONS
   People are more comfortable saying no than yes.
   "Would it be ridiculous to consider...?"
   "Is it a bad idea to...?"

6. THE LATE NIGHT FM DJ VOICE
   Slow. Calm. Deep.
   Triggers trust at a subconscious level.

THE ACKERMAN MODEL (negotiating price):
Start at 65% of target → 85% → 95% → 100%
Use odd numbers. Add non-cash item at the end.
```
