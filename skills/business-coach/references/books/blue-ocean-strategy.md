## THE ONE LINE
Stop trying to beat the competition — make it irrelevant by creating new market space (a "blue ocean") where you set the rules.

## THE CORE INSIGHT — RED OCEAN VS BLUE OCEAN

```
RED OCEAN                          BLUE OCEAN
─────────────────────────          ──────────────────────────
Existing market, fixed boundaries  Uncontested space, you define them
Beat competition                   Make competition irrelevant
Exploit existing demand            Create and capture new demand
Value-cost trade-off               Break the value-cost trade-off
Align activities to differentiate  Align activities to value innovation
OR keep cost low
```

**Value Innovation:** Pursue differentiation AND low cost at the same time. Eliminate or reduce factors the industry takes for granted; raise or create factors buyers truly value. The trade-off you've been told is iron law turns out not to be.

## THE FIVE FRAMEWORKS

```
1. STRATEGY CANVAS    — Diagnostic. Plot competing factors vs offering level.
2. ERRC GRID          — Generate value innovation: Eliminate / Reduce / Raise / Create.
3. SIX PATHS          — Find blue ocean opportunities.
4. THREE TIERS        — Expand demand beyond current customers.
5. STRATEGIC SEQUENCE — Test commercial viability before launch.
```

## THE ERRC GRID — FOUR ACTIONS

```
The mechanism for value innovation. Pull all four levers at once.

╔══════════════╦══════════════════════════════════════════════════════╗
║   ACTION     ║   QUESTION                                            ║
╠══════════════╬══════════════════════════════════════════════════════╣
║  ELIMINATE   ║ Which factors that the industry takes for             ║
║              ║ granted should be eliminated entirely?                ║
║  ↓ COST      ║                                                       ║
╠══════════════╬══════════════════════════════════════════════════════╣
║  REDUCE      ║ Which factors should be reduced well below            ║
║              ║ industry standard?                                    ║
║  ↓ COST      ║                                                       ║
╠══════════════╬══════════════════════════════════════════════════════╣
║  RAISE       ║ Which factors should be raised well above             ║
║              ║ industry standard?                                    ║
║  ↑ VALUE     ║                                                       ║
╠══════════════╬══════════════════════════════════════════════════════╣
║  CREATE      ║ Which factors should be created that the              ║
║              ║ industry has never offered?                           ║
║  ↑ VALUE     ║                                                       ║
╚══════════════╩══════════════════════════════════════════════════════╝

KEY: Breakthroughs almost always come from ELIMINATE + CREATE.
     REDUCE and RAISE only adjust within the industry's existing rules.
     ELIMINATE and CREATE break those rules.
```

## STRATEGY CANVAS — THE DIAGNOSTIC

```
Y (Offering level)
HIGH ┤
     │              ●─●─●           ← Competitor A (full-service)
     │        ●─●─●                 ← Competitor B
     │  ●─●─●                       ← Industry average
     │
     │  ─────●         ●            ← YOUR blue-ocean curve
     │                  ●─●─●       (cuts factors, raises others,
     │                              creates a new one — visible
LOW  ┤───────────────────────       divergence from the pack)
       F1  F2  F3  F4  F5  F6
              X (Competing factors)
```

A strong strategy curve has all three:
- **Focus** — disproportionately invests in a few factors, not spread thin
- **Divergence** — looks different from competitors' curves
- **Compelling tagline** — captures the strategy in a memorable phrase

**Iconic taglines:**
- Southwest: *"The speed of a plane at the price of a car — whenever you need it."*
- [yellow tail]: *"A fun and simple wine to be enjoyed every day."*

**Caveat:** The X-axis is subjective. The factors you choose to plot define the analysis. The framework presents as rigorous diagnostic; it's actually a structured argument.

## THE SIX PATHS TO BLUE OCEANS

```
PATH 1: ALTERNATIVE INDUSTRIES
        "What did customers reject when they chose us — and why?"
        → NetJets across corporate jets + first-class commercial
        → Home Depot across contractors + pro supply + hardware stores

PATH 2: STRATEGIC GROUPS
        "What makes customers trade up or down between groups?"
        → Lexus: luxury performance at mid-range price
        → Curves: stripped gym for women at low price

PATH 3: CHAIN OF BUYERS
        Three roles: purchasers (pay), users (use), influencers (recommend).
        Switch focus → new market.
        → Novo Nordisk NovoPen: sold to patients (users), not doctors
        → Bloomberg: sold to traders (users), not IT (purchasers)

PATH 4: COMPLEMENTARY PRODUCTS/SERVICES
        "What pain happens before, during, or after our product is used?"
        → NABI buses: fiberglass + complementary services
        → IKEA: childcare + cafeteria + flat-pack

PATH 5: FUNCTIONAL VS EMOTIONAL APPEAL
        Industries default to one. Flip it.
        → Body Shop: stripped emotional cosmetics into functional
        → Starbucks: turned commodity coffee into emotional experience

PATH 6: TIME / TRENDS
        Find a trend that is DECISIVE, IRREVERSIBLE, and has CLEAR TRAJECTORY.
        → Apple iTunes: anticipated digital music + piracy collapse
        → Cisco: anticipated networked-world bandwidth demand
```

## STRATEGIC SEQUENCE — TEST BEFORE LAUNCH

```
1. UTILITY    → Buyer Utility Map: are there empty cells you can fill?
                ├─ NO  → Stop. Rethink.
                └─ YES ↓

2. PRICE      → Price Corridor of the Mass: accessible to the mass?
                ├─ NO  → Re-engineer the offer.
                └─ YES ↓

3. COST       → Strategic price minus target margin = target cost.
                Can you hit it through cost innovation or partnering?
                ├─ NO  → Find cost innovations or partner.
                └─ YES ↓

4. ADOPTION   → Address all THREE stakeholder hurdles:
                  • Employees (job security)
                  • Partners (disrupted relationships)
                  • Public (ethical / safety)
                ↓

   COMMERCIALLY VIABLE BLUE OCEAN
```

**Price-minus costing** (not cost-plus):

```
Strategic price (set in step 2)
−  Target margin
= Target cost (NON-NEGOTIABLE)
```

## THREE STRATEGIC PROPOSITIONS — ALL MUST ALIGN

```
╔══════════════╦════════════════════╦═══════════════════════════════╗
║ PROPOSITION  ║ FOR WHOM           ║ QUESTION                       ║
╠══════════════╬════════════════════╬═══════════════════════════════╣
║ VALUE        ║ Buyers             ║ Exceptional buyer value?       ║
║ PROFIT       ║ Company            ║ Generates profit?              ║
║ PEOPLE       ║ Employees,         ║ Motivates everyone whose       ║
║              ║ partners, public   ║ support you need?              ║
╚══════════════╩════════════════════╩═══════════════════════════════╝
```

Skip any one and execution dies. Tata Nano had value + profit but failed the people proposition (Singur protests + "cheap car" stigma).

## FAIR PROCESS — THE 3 E PRINCIPLES

People will sabotage even a perfect strategy if they feel it was imposed unfairly.

- **Engagement** — Involve people in decisions that affect them
- **Explanation** — Tell them WHY decisions were made
- **Expectation Clarity** — Make clear what's expected after the decision

**Elco Plant lesson:** Two plants, same strategy. The cooperative non-union plant got NO fair process and rebelled. The strong-union plant got full fair process and cooperated. The "easy" plant failed; the "hard" plant won.

## THE 10 RED OCEAN TRAPS

```
 1. Customer orientation                — Look at NONcustomers first
 2. Going beyond existing industries    — Most blue oceans are adjacent
 3. "Tech innovation = blue ocean"      — No: VALUE innovation does
 4. First-mover advantage worship       — 90% of pioneers fail (Tellis & Golder).
                                          First to get VALUE-COST right wins.
 5. Differentiation = premium pricing   — BOS is both/and, not either/or
 6. Low cost = low pricing              — Price strategically against alternatives
 7. "Innovation" broadly                — Must be VALUE innovation specifically
 8. Niche thinking                      — Niches are small red oceans
 9. Winning the competition             — Irrelevance > winning
10. Disruption as the only path         — BOS embraces nondestructive creation too
```

## ICONIC CASES — WITH HONEST DECLINE NOTES

Many BOS case studies are taught as canonical wins. Several later collapsed. Cite carefully.

```
Cirque du Soleil    — Circus + theater hybrid.    (Filed for bankruptcy 2020)
Curves              — Women's circuit gym.        (Filed for bankruptcy 2014)
The Body Shop       — Functional cosmetics.        (Entered administration 2024)
Yellow Tail wines   — Easy-drinking wine.         (Heavily eroded by imitators)
NTT DoCoMo i-mode   — Mobile internet first.       (Crushed by iPhone post-2007)
NABI Buses          — Fiberglass + services.       (Distressed sale 2013)
Southwest Airlines  — "Speed of a plane..."        (Ongoing operational pressure)

Still solidly winning:
Novo Nordisk        — Switched buyer chain (patients, not doctors). 70% of revenue.
Bloomberg           — Switched buyer chain (traders, not IT).
Salesforce          — Created the SaaS category.
```

The framework's intellectual honesty problem: when a BOS-cited company fails, the response is "they stopped applying it" — making the theory hard to falsify. **Treat it as a thinking discipline, not a recipe.**

## DECISION TREE — ARE WE IN A RED OCEAN?

```
Competitors all doing roughly the same thing?
├─ YES → Red ocean
└─ NO  → Margins shrinking despite improvement?
         ├─ YES → Red ocean trending to commodity
         └─ NO  → Run a Strategy Canvas.
                  Curve has Focus + Divergence + a tagline?
                  ├─ All 3 YES → Blue ocean
                  └─ Any   NO  → Red ocean or weak strategy
```

## WHEN NOT TO USE THIS FRAMEWORK

```
Operational / execution problem        → BOS is for strategy reframing — skip
Founding-stage validation              → Use Mom Test first
Mature, stable market with healthy
competition and defendable position    → You probably don't need BOS
Network-effect / two-sided platform    → BOS handles these poorly
AI-native fast-cycle category          → Cycle too fast for BOS timelines
```

## INTEGRATION WITH OTHER FRAMEWORKS

- **Porter's positioning** is *complementary*, not competing. Use Porter when industry structure is stable. Use BOS when you're trying to escape red-ocean dynamics.
- **Mom Test / Lean Startup** validates whether the blue ocean you imagined is the one customers actually want.
- **$100M Offers** turns the BOS value proposition into a concrete grand-slam offer.
