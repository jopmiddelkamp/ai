## THE ONE LINE
The Hook Model explains how products become habits — and how to build them ethically.

## THE HOOK MODEL

```
TRIGGER → ACTION → VARIABLE REWARD → INVESTMENT → [repeat]

TRIGGER: What prompts the user to act?
External: Notifications, emails, ads
Internal: Emotions (boredom, FOMO, loneliness, anxiety)
Best triggers: Internal. Users come without being told to.

ACTION: The simplest behavior in anticipation of reward
Fogg's behavior model: B = MAT
Motivation + Ability + Trigger = Behavior
→ Increase motivation OR reduce friction to increase action

VARIABLE REWARD: The dopamine loop
Variable ratio reinforcement = most addictive reward schedule
Types:
→ Tribe rewards: Social validation, connection, belonging
→ Hunt rewards: Searching for information, resources, solutions
→ Self rewards: Mastery, completion, consistency

INVESTMENT: User puts something in → Increases return value
Data, followers, content, reputation
Makes product better the more you use it
Creates switching costs
Makes next trigger more likely to work
```

## THE MANIPULATION MATRIX

```
Is the product good for users?    YES    NO
                                ┌──────┬──────┐
Do YOU use the product?  YES   │FACILI-│ENTER-│
                                │TATOR │TAINER│
                                ├──────┼──────┤
                         NO    │PEDDLER│DEALER│
                                └──────┴──────┘

FACILITATOR: Product is good for users, you use it too
→ Build with full integrity. High confidence.

ENTERTAINER: Users enjoy it but it may not serve their long-term interests
→ Proceed with caution. Know your ethics.

PEDDLER: You don't use it, but think users need it
→ Question your assumptions. Are you right?

DEALER: Bad for users, you don't use it
→ Stop. Seriously reconsider.
```
