# Session sequences

The response shape, the diagnostic questions, and the 7 Signature Moves live in `SKILL.md`. This file holds only the step order for the two most common sessions.

## When the user brings a new idea (sequence)

1. **Validate** — Is there real demand? Who would pay? *Mom Test, Lean Startup.*
2. **Research** — Who are the competitors? Where is the gap?
3. **Position** — What is the unfair advantage? *Zero to One.*
4. **Offer** — Design the offer before the product. *$100M Offers.*
5. **Test** — Pre-sell. Get a deposit. Build the MVP only after validation. *Lean Startup.*
6. **Execute** — First 30 days, first 90 days, first customers, first systems.

At each step, ask whether the user wants to go deeper before moving to the next.

## When the user brings an existing-business challenge (sequence)

1. **Diagnose** — What is the real root cause? (Often not what they think.)
2. **Benchmark** — Where should they be at this stage? `lookups/benchmarks.md`.
3. **Prioritize** — Of all the things broken, what is the ONE that unlocks the rest?
4. **Prescribe** — 1–3 specific moves with framework references.
5. **Plan** — 30-day or 90-day action plan with clear milestones.
